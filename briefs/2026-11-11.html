官方·Berkeley RDI ↗AIHOT ↗

其实现在软件开发的瓶颈早就不是如何构建出来专业软件了，而是其他方面。 一个是如何更好的让 Agent 用你的软件。 我的绝大部分专业工作已经不再依赖于软件，而是给 Agent 一个指令，让它去帮我完成，比如视频剪辑。 这就意味着像视频这种这么复杂的软件操作界面，在 Agent 来说是几乎没有价值的，让 Agent 去通过 GUI 操作软件是低效的，Agent 最友好的方式是 cli、MCP和代码。 另一个是如何让人类更好的去预览和微调 以前的软件做这么复杂都是因为需要人去全程操作，但是当我们把这些繁琐的操作叫给 Agent 之后，人需要做的只要去检查 Agent 完成后的结果，以及对结果进行标记、评论和微调。 所以如果你要做一个视频编辑器，不要再做一个这么复杂的界面，一个视频播放器能看到生成的结果，一个可以用来标记、评论的工具配合就足够了。我觉得哪里生成的不对，标记一下、写两句评论就可以了。 这一点连 Manus 都没想明白，他们新版本的视频生成功能还是在配合一个复杂的 Timeline 视频编辑器。 还有一个就是如何更好的满足用户个性化的需求 以前的软件设计，只能取最大公约数，照顾绝大数人的需求，所以像一些巨无霸软件 Office、CapCut 都很专业，需要操作手册才能用明白，一些个性化的需求也很难满足。 但现在不一样了，Agent 让制作软件成本很低，所以人人都在做自己的个性化软件，比如我看到向阳就在做自己的录频软件，就是为了满足很多他自己的需求：美颜、虚拟主播。 这种长尾需求是真实存在的，以前没办法，成本太高，现在很多人自己动手，但更多的人即使有 AI 也没有这个能力和足够的 Token 来做这个事情。 这意味着未来的软件，功能上会原子化，软件的能力会被细分拆解到一个个 cli 的命令、MCP 的调用上，Agent 根据需要做的事情，用脚本当胶水，按需组合出来需要的功能。 软件提供的是原子化的能力，不再需要复杂的 UI，只要让 Agent 动态生成就足够了。 最后一点，当人人都能做软件，怎么才能把你的软件卖出去？ 这是个思考题，我也没答案，我也卖不出 😂
